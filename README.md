# Dekho (দেখো)

A free, offline, ad-free file viewer for Android. Bangla and English interface.

- **PDF**: read, select and copy text, highlight, notes, signature, delete pages, save/share
- **DOCX**: readable view with bundled Bangla font
- **XLSX / CSV**: table view with sheet tabs
- **HTML, Python, JS, JSON and other code**: syntax highlighting, copy all, HTML preview
- **Images and text files**
- Opens from the file manager via "Open with → Dekho"

## Build the APK

1. Upload all files in this folder to the root of a GitHub repository.
2. Create the workflow: Add file → Create new file → name it `.github/workflows/build.yml`, paste the contents of `build.yml`, commit.
3. Open the Actions tab → "Build APK" → when it finishes, download `Dekho-APK` and install the APK.
